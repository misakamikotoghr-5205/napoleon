# 拿破仑：鹰旗军需官 (Napoleon: Eagle Quartermaster) v2.0

**《拿破仑：鹰旗军需官》** 是基于 Godot 4.7.1 构建的沉浸式长篇历史叙事、卡牌与骰子收集、3D 战棋策略游戏：从 **1793 年土伦围城** 一路推进至 **1814 年厄尔巴岛分岔**，并完整开放三条命运分支的首章（**《鹰飞》百日王朝与滑铁卢之夜**、**《伊夫堡》基督山马赛暗流**、**《远洋》贝勒罗丰号与圣赫勒拿孤岛**）。

---

## v2.0 核心特性

1. **分场景中世纪 / 古典史诗独立 BGM**
   - 6 首立体声中世纪与古典管弦/鲁特琴配乐，随界面状态自动平滑切换：
     - `title.ogg`（标题界面 · 古典史诗管弦序曲）
     - `story.ogg`（长篇剧情与收集阶段 · 中世纪鲁特琴、竖琴与叙事大提琴）
     - `camp.ogg`（营地整备 · 温暖木管与室内弦乐）
     - `battle_prep.ogg`（战前点兵与部署 · 低沉军鼓与铜管蓄势）
     - `battle.ogg`（3D 战场交锋 · 急促战鼓、军号与高张力交响进行曲）
     - `victory.ogg`（凯旋与结算 · 辉煌铜管礼赞）

2. **沉浸式长篇剧情驱动（无大地图干扰、无一天时限压力）**
   - 彻底移除大地图跑格与“一天时限”限制（默认开启 `DEHOUDANG_NO_MAP=1`），玩家可从容阅读长篇历史叙事、查验全部物证并收集军需物资。
   - 全线主干与三大分支剧本扩充 3 倍以上（共 995 段长篇历史对白与心理描写）。

3. **剧情内嵌【卡牌打出 + 骰子检定收集】栏**
   - 在阅读长篇剧情与抉择界面底部直接内嵌 **【剧情内卡牌打出 & 骰子收集栏】**：
     - **掷骰行军收集**、**营令三色旗切换**、**密探情报征集**、**军工与同盟建设**、**行军道具使用**、**伙伴招募** 均可边看剧情边直接打出。

4. **全程新手教程横幅 & 战前战术指引**
   - 剧情顶部常驻 **4 步新手指引横幅**，抉择页底部配备 **【战前准备与 3D 战场战术指南】**，出征排兵与 3D 战场内均配备分步战术提示。

## 运行与打包说明

```sh
# 直接启动《拿破仑：鹰旗军需官》
godot --path .

# 运行远洋与拿破仑战役自动化测试套件
OCEAN_SUITES=vn,content,hub,battle_hud,napoleon_demo GODOT=godot JOBS=2 bash tools/run_ocean_tests.sh

# 导出 Windows 独立单文件可执行程序 (.exe)
mkdir -p export/napoleon-demo
godot --headless --path . --export-release "Windows 拿破仑分支试玩"
```
