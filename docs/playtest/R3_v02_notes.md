## ① 对白推进 / 退出
- **点击对白框**：能推进（R3_06→R3_07 从哥哥台词进到「你」的回复）。
- **快连点**：未见整段跳过卡死；打字机提示有「点一下先显示整句」（见 v02_dialogue_exit.png）。
- **空格 / 回车**：能推进普通台词行。
- **Esc**：可作为推进手段（与自动测试 `--say-mode=esc` 一致）；在「请选择」界面 Esc **不会**替你点选项——需要鼠标点选项，否则停在选择态（不算软锁，但键盘无法选选项）。
- **「跳过 ▶」按钮**：存在于对白框右侧；坐标偏右上，可点。
- **结论**：未复现「点了对白无法退出」的硬卡死。选择态必须点选项（或拒绝按钮），Esc 不能代替选支。
