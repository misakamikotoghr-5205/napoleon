# R2 序章试玩笔记（德厚当，首次玩家视角）

流程：开张 → 烛火 → 柜台教学(哥哥) → 后门教学(陈叔叔) → 「第一天」→ 小丁(收购大米)走完收购/收物。无崩溃、无报错弹窗（日志只有 ALSA 无声卡/V-Sync 警告，属环境问题）。

## 严重 / 较明显
- **教学说“推进典当盒”，实际是“点物品 → 再点典当盒”（不是拖拽）**。第一次我按字面拖拽，物品没反应，卡了几轮；只有黄框选中 + 抽屉橙框高亮作提示，没有“先点物品，再点高亮的盒子”的文字。（R2_13、R2_14）
- **点击对话过快会跳过台词**：打字机未播完连点会连跳多句，首次玩家容易漏掉教学内容；也没有“点一次先补全本句”的明确反馈。（后门教学段，R2_06 / R2_08）
- **鉴定面板（放大镜结果）选项被裁切，且出现滚动条**：下方选项显示不全，需滚动才能看到。（R2_11、R2_12）
- **右侧面板遮挡/拥挤**：物品面板与右侧 HUD 叠在一起；“待办”列表文字被截断。（R2_04、R2_11）
- **小丁“客人底价：25 麸”直接明示**在右侧面板，议价的悬念被取消（若是教学期故意给，应加一句说明；若不是，是信息泄露）。（R2_10 / R2_12）

## 中等
- **角色名低对比度**：“哥哥”“陈叔叔”名牌几乎看不清。（R2_06）
- **烛火段“远处有狗”被截成半句/淡出过快**。（R2_02）
- **账本里的货币字（麸/铜钱面值）辨识不清**，像素字太小。（R2_05）
- **算盘位置提示有误导**：提示箭头指向的位置与真正可点热点不一致（抽屉 vs 放大镜同样出现过）。（R2_03 / R2_04）
- **热点矩形很淡**，不知道哪些可点；棋子与背景颜色接近，几乎看不见，点到才知道。（R2_07）
- **选项菜单结构怪异**：出现空白选项行；旗子选项分支对话。（R2_08）
- **连续性问题**：哥哥已经去开门，柜台上仍显示哥哥。（R2_06）
- **台词重复舞台指示**：“（笑了笑）对了，听人说……”之前已出现过同样的“（笑了笑）”。（R2_13）
- **右侧面板过期信息**：交易结束后右侧仍显示旧客人信息。（R2_14）

## 小问题
- **悬浮提示(tooltip)残影**：鼠标停在物品上后，提示“粳米(一小袋,三十来斤)”会残留在左下垃圾箱附近，位置不跟随光标，看起来像拖拽残影。（R2_14 前后）
- 右上 HUD（行情、口碑）字太小、对比度低。
- 接受报价后米袋短暂消失再出现，像卡了一下；之后需手动搬运，节奏上有点断。
- 无 tofu 方块字；中文字体显示正常。
