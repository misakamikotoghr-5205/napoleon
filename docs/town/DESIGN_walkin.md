# 只守铺子版：过路客人、门口吆喝、架上的货要等买主进门谈（v0.4.2 设计）

主创试玩反馈（2026-10-11）：
> 玩家需要能主动呼叫客人，或者客人应该不间断地进门。而且为啥我货架上的东西能直接卖出？应该有人进来对话，进行一番交流讨价还价之后再卖啊。

现状（详见本次代码梳理）：
- 客人只在黎明一次排好（`NpcLife.plan`），只落在 9/12/15/18 点四个一小时的窗口，每天约 3.6 位外加胡二；06–09 点永远没人，09–18 点里最长的空档中位数约 230 游戏分钟（约 2.7 分钟真实时间），只守铺子模式下这段时间玩家无事可做。
- 货架面板上的「卖掉」按钮直接按市价 92% 卖给看不见的“市场”账户，不说话、不花时间；夜里的「夜卖」也是同样的瞬间成交。
- 柜台上“客人进门、问价、讨价还价、买走架上的货”这套（`Session` 的 sell 模式）其实已经有了，只是买主少（约 0.95 位/天，36% 的天一个都没有），而且要买的货在黎明就定死了（库里最早的两件），货被卖掉或被胡二拿走以后，买主到了柜台就只能干站着。

## 一、过路客人：白天一直有人进门

- 只在“只守铺子”模式开（数据开关在 `data/town/walkin.json`；`--shop-only=0` 的小镇版不受影响）。
- 从第 2 天起（第 1 天剧情客人已经很满）过路客人到点自己进门。每天黎明排一张“过路客人”时刻表（第 1 天也排，`calls_from_day`=1）：从 `open_minute`（07:00）起，每隔 `gap_range`（数据给，初值 35–80 游戏分钟；10 天实测后调为 55–110，见 `docs/town/walkin_balance.md`）一位，到 `last_minute`（17:30）为止。时刻用 `JevRng.draw(seed, "walkin_gap", [day, k])` 定，同种子同一天永远一样；不碰天气、米价、外生轮盘。
- 第 1 天（`from_day` 以前）表上的人到点不自己进门，从门口走过去（`passed`）；哥哥交代完（`town_first_open`）以后到门口吆喝，照样叫得来下一位（见二）。哥哥第一天就说“人不来，就到门口吆喝一声”，这句话当天就算数。
- 到点时，如果店里已经站着 `max_waiting`（3）位或更多在等的客人，这位就不进门（门口探头看看就走了，不记账、不报错过）。吆喝叫来的人除外：吆喝时已经数过，他到门口时店里满了也照样进门（第四位往后排着站）。
- 进门的人是“过路客人”：身份从 `town_pack` 的陌生人原型里抽（外乡人、挑货的、学生、过路客、收旧物的——收旧物的仍要码头开了才来），名字用原型名，立绘用 `art/portraits/stranger_<原型>.png`，ID 用自己的命名空间 `walkin:<原型>#d<天>_<序号>`，访问 ID `walkin_d<天>_<序号>`，不和自然排的客人、故事卡撞。
- 来意按数据权重抽：当东西、卖东西给铺子、买架上的货（架上没有他买得起的货时，“买”改抽成别的）。实测后过路的少当多卖（生客不回来赎，当本压满当期），见 `docs/town/walkin_balance.md`。
- 等的耐心 `patience_range`（初值 40–90 分钟）。没等到就走的过路客人，日结里只合成一行“还有 N 位过路的没等到”，不一条条列。
- 胡二闹到“街坊绕着走”的那一天（boycott）：没有过路客人，吆喝也没人应。
- 时刻表和已经来过几位都存在 `director.vars["town"]["walkin"]`，读档后不重排、不重复进门。

## 二、门口吆喝：玩家主动招人

- 只守铺子模式下，门口的提示从“门口”改为「【E】门口吆喝」。按 E（只有按 E，走进门口那一格不触发）打开一个小窗：
  - **吆喝收当**：“有东西要当、要卖的，进来看看！”——招来一位要当东西或卖东西给铺子的人。
  - **吆喝卖货**：“架上有好东西，进来瞧瞧！”——招来一位想买架上货的人。架上没货时这一项灰着，写“架上没货”；架上有货、可没一样是过路的人看得上、买得起的（按原型口味和肯看的价），也灰着，写“过路的看不上”（不写数），硬吆喝说“架上这几样，过路的人看不上，吆喝了也没人进来买。”
  - **算了**。
- 吆喝花 `call_minutes`（初值 10）游戏分钟。被招来的人 `call_delay`（初值 3–12 分钟）后进门。
- 吆喝不凭空多造人：它把今天时刻表上“下一位还没到的过路客人”提前叫来，并按吆喝的种类定他的来意。今天的人都来过了，就说“街上没什么人了，明天早些吆喝”。店里已经等着的，加上吆喝叫来、还在路上的，够 3 位时说“店里还站着人呢，先招呼他们”。天黑（18:00 以后）说“天晚了，街上没人了”。第 1 天哥哥还没交代完时说“门板还没卸完，先听哥哥把话交代完。”
- 这些话都是游戏里的一句话（气泡/提示），不出现任何数字或机率。

## 三、架上的货：只能等买主进门谈

- 只守铺子模式下，货架面板去掉「卖掉」按钮，改成只看：一行一件，写名字、类别、成色，和“当初收价 X 蚨 / 满当的当本 X 蚨 / 店里旧存”（都是玩家自己账上的数，不再写“市价约”，免得买来的假货露底）。面板上一句话：“想卖，到门口吆喝一声，买主进门在柜台上谈。”
- 只守铺子模式下，夜里的「夜卖」不出现。夜里「对账」的库存、「整理库房」挑哪一件、整理后的那句话也不写市价，写自己账上的数（同货架）；整理库房的说明不写“+5%”（`shop_only.json` 的 `night_desc`）。哥哥在旁边时柜台上卖货也不报“市价合计”。
- 想买货的人（过路的、吆喝来的）进门时，从**当时**架上挑一件（按原型口味加权、只挑他买得起的，`JevRng.draw(seed, "walkin_pick", [day, n])`），到柜台上：
  - 先说要哪件：“掌柜的，架上那件{名字}，我看看。”
  - 柜台上有两三句可以问的（“问他买去做什么”“请他上手看看”），回答按原型写在数据里，只说观察，不报价。
  - 然后在算盘上谈价：沿用现有 sell 模式（他先报个价，你报价，他还价或走人），一次只谈这一件。
  - 谈成：钱从他身上付给你，货归他，记一笔账目，提示“卖出：{名字}，进账 X 蚨”。
- 买主到柜台时那件货已经不在了（被卖了、被胡二拿走了）：他改挑架上另一件他买得起的，先说出原先看中的是哪件（“我是冲架上那件××来的——没了？那这件××，我看看”）；一件也没有就说“我是冲架上那件××来的——没了？那改天再来”，体面地走，不卡住。黎明排好的自然买主也补上这条：要的货都不在了，说出想看的是哪件（哪几件；只一件时不说“那几样”），一句走人，不再干站着。

## 四、告诉玩家（规矩写在世界里）

- 第 1 天哥哥交代铺子的规矩时加两句：“人不来，就到门口吆喝一声。”“架上的东西别急着出手，等买主进门，在柜台上谈。”当天交代完就能吆喝。
- 柜台上、侧栏、档案簿里过路客人写原型名（挑货的、外乡人……），不露 `walkin:` 这串 ID；档案簿“人物”不给过路客人、生客一人一张，末尾合成一行“过路客人：接待过 N 位”。学生没有自己的立绘，借外乡人的（`stranger_refugee`）。
- 档案簿“规矩”里的“卖货”一页、“柜台”一页按只守铺子版改写（不再提集市、茶馆、出门办事；写明开张第二天起过路的人才自己进门，头一天要吆喝）；F1 操作说明同步。
- 新手引导：第一次店里空着超过一阵（约 60 游戏分钟，从第 2 天起），门口亮一下，气泡“没人上门，就到门口吆喝一声”。

## 五、不变的东西

- 胡二每天的保护费照旧；柜台的验货、议价、当票都照旧。
- `--shop-only=0` 的小镇版：不开过路客人、不改门口、不改货架（那边有茶馆、集市等别的卖法）。
- 无头的 `town_action("sell")` 接口保留（T04 的自动试玩和验收还在用），只是只守铺子版的界面不再调它。
- 所有新数值都在 `data/town/walkin.json`，不改 `town_pack.json`（不让旧存档失效）。
