## 0. 一句话

**以前：** 一张柜台，客人排队进来，验货、砍价、下一位——这就是 Probably Stolen 的骨架。
**以后：** 一个会自己过日子的江南小镇。当铺只是你家那一栋楼；你每天要决定什么时候守柜台、什么时候出门办事。当票、赊账、人情在几周里慢慢收场。镇上的店随着事情发生一家家开门，警察所也在其中。每天的开销是几笔会变的账，不是一个固定的数。

主创原话定下的身份不变：“你经营的是财物，更是在一个不由自己掌控的时代中，与具体的人打交道。”

## 1. 和 Probably Stolen 的结构性区别

| | Probably Stolen | 德厚当 v0.4 |
|---|---|---|
| 一局的单位 | 一个房间里的客人队列 | **小镇里的一天**：几点去哪儿是你的选择（清早去茶馆听消息、上午去米行、下午守柜台、宵禁前回家） |
| 核心对象 | 要倒手的货 | **随时间展开的合同**：当票（当期、月息、续当、赎当、满当）、赊账、借据。情感高潮是“赎当那天她来了”，或者没来 |
| 卖货 | 同一房间的展示柜 | **铺子里的满当货架**（客人可单件买）＋镇上的出货渠道：集市日的估衣摊、茶馆里找买主、卖给药铺/银楼 |
| 客人 | 生成器堆出来的一叠人 | **有住处、有日程、有家人和债的镇上人**；街上也能遇见；陌生人坐船来 |
| 执法 | 检查官扫违禁、罚款、开枪 | **机构是具体的人**：会来当老婆镯子的巡长、可以讨价的保长摊派、维持会。没有枪战 |
| 压力 | 租金/贷款倒计时 | **几笔会变的家用**（米价、柴炭、药、人情、摊派），每笔都提前看得见来源，后果有延迟 |
| 信息 | 晨报界面 | **流言网络**：茶馆、来信、电报、告示墙；〔亲眼〕〔听说〕〔推测〕 |
| 进度 | 许可证、机器、升级 | **镇子一家家开门**：靠时间主干、人际、事件；年末选择继续当铺还是转行 |

同时**不用** PS 的标志性界面：网格背包旋转、按铃叫下一位、拉卷帘门打烊、表情脸声望、真/假对质屏、每类物品一个小游戏。

## 2. 一天怎么过（核心循环）

时间像星露谷一样走钟：**早 6:00 起床 → 21:00 宵禁（维持会规定，街上被巡逻撞见有后果）→ 夜里在家/后门 → 睡觉**。对话、柜台交易、看账时钟暂停【原型默认：1 游戏分钟 ≈ 0.7 秒现实时间，一天现实约 12 分钟】。

1. **清晨（在家）**：看门缝塞进来的告示、米行挂出的牌价（出门路过才看得到）；决定今天吃什么（稀粥 / 家常 / 像样，钱和体力不同）；翻账簿看今天谁的当期到了。
2. **白天（自由安排）**：
   - **守柜台**：挂上门旗、站到柜台后，生成器排好的客人才会进门。你不在，他们会等一会儿，然后走（有的改天再来，有的不会再来）。
   - **出门办事**：去米行买米/赊账，去茶馆听消息、找买主，去保公所交摊派或讨价，去邮电局取信，集市日去估衣摊卖满当货……
   - **这就是取舍**：出门的时间就是不守柜台的时间。后期可以雇学徒看铺（有风险）。
3. **傍晚**：收铺、点账（钱匣、放出去的钱、该收的钱、冻结的钱分开显示）。
4. **夜里**：后门、电报机、整理库房、烧东西——沿用现有夜间系统，改成在家里走动操作；熬夜能多办一件事，第二天体力差。

**一天的期待**（归档原话）：今天会遇到谁；手里这份当物与承诺以后怎样收场；熟悉的人和地方又发生了什么变化。普通日子本身就是内容。

## 4. 每天的生存压力：几笔会变的账

固定数字改成**几条不同性质的家用账**。每条都有看得见的来源和日期，跳过的后果有延迟（Papers Please 的规则），多数可以赊、可以拖、可以谈。

| 账目 | 多久一次 | 怎么变 | 你在哪儿提前知道 | 不付会怎样（有延迟） |
|---|---|---|---|---|
| **伙食** | 每天 | 米价是“世界轮盘”的随机游走：均值回归＋冲击（米船没到、封锁、新米上市） | 米行牌价、茶馆传言 | 吃差一点：体力降；连续两天饿：生病 |
| **柴炭灯油** | 每天，按季节 | 天气轮盘（倒春寒、连阴雨） | 黄历、天色 | 冷：生病风险；没灯油：夜里做不了事 |
| **药** | 只在生病时 | 由上面的饥寒连带，或镇上疫病轮盘 | 济生堂看病 | 拖着会变重（罕见、提前有征兆） |
| **人情** | 看镇上的事 | NPC 的红白喜事、满月、探病 | **请帖提前 3–7 天到** | 不花钱花关系；缺一次不会绝交 |
| **摊派 / 维持费** | 每周＋不定期 | 维持会的“怀疑”与口碑、上头的指令 | 马保长上门、告示墙 | **可以讨价还价**（复用议价系统）；拖欠会被盯上 |
| **房捐 / 铺租** | 每月 | 只能由告示提前 7 天以上改 | 告示＋万年历 | 警告 → 罚 |
| **良民证** | 每人一次，会涨价的传言 | 维持会 | 告示墙、流言 | 出镇、过桥被查 |
| **突发** | 少见，有冷却 | 大风修瓦、被偷、罚款 | 当天告示 | 当场或赊 |
| **周转** | 看合同 | 谁来赎当、什么时候、还不还得起（能力≠意愿） | 账簿 | 现金吃紧 → 钱庄/拿自家东西抵押 |

公平规则（来自调研与归档）：
1. 每笔钱都有来源和日期，没有夜里偷偷扣的钱（真正的急事除外，有冷却上限）。
2. 显示区间、不显示秘密：牌价是今天已经摇出来的数，不预告未来。
3. 后果滞后、逐级升级，给你周转的空间。
4. 有缓冲：米行赊账（额度看口碑）、宽限、拿自家东西去当、钱庄借钱。
5. 有对策：多囤米（会受潮）、换便宜粮、以物易物。
6. 准备不受惩罚：存粮改变你扛事的能力，不改变摇出来的结果。
7. 难度用三种“年景”代替难度条：**太平年 / 常年 / 乱世**（对应 RimWorld 的三种叙事者节奏）。
8. 1938 年米价其实还算稳，1939 年起才飞涨——所以前期波动小、后期由历史本身加压，不靠涨租逼人犯罪。

## 5. 随机性：GameJev 生成器怎么驱动小镇

**原则：固定主干＋随机血肉。** 主线（父母失踪、陈叔叔、德字第一九六号、哥哥的信、维新政府成立）是钉死的日程；其余由生成器每天摇。

### 5.1 随机数
沿用 GameJev 的 `draw(种子, 领域, 语义键)`（SHA-256）——已移植到 GDScript 并与 Python 逐位一致。每个子系统（天气、米价、每栋楼、每个 NPC）一条独立的流：你的操作永远不会“用掉”一次天气的随机数；存档读档、预览选项都不会改结果。**每局新开随机种子**（现在的版本种子写死了）。

### 5.2 每天早上生成器按顺序做
1. **压力值**走一步：米价、药价（外生，均值回归＋噪声）；怀疑、动荡（内生，只由镇上发生的事推动，按半衰期回落）。
2. **世界轮盘**（外生，不读玩家）：天气、米船、战事消息、节令。每个轮盘都有“无事”这一格，大多数日子是平常日子。
3. **镇务轮盘**（内生）：维持会摊派、巡逻、搜查（受“怀疑”影响，有冷却）。
4. **每栋已开门建筑的事件卡组**（故事卡）：米行“米船到埠”、药铺“歇业一日”、茶馆“说书先生来了”、码头“来了个生人”……
5. **解锁检查**：满足条件的建筑开门，并发一条镇上消息。
6. **当天的账**：按第 4 节算出各笔开销。
7. **来访计划**：哪些熟人今天会来当铺、什么时候、来干什么（当、赎、卖、买、打听、求情），由他们的日程、手头紧不紧、听到的流言、手里有没有你的当票决定；**陌生人**（难民、销赃的、收古董的）按动荡程度和集市日多少不等。来的人可以**不止一个**——周妈陪林嫂来说情。
8. **当物生成**：每件东西从物品模板里摇出品级、成色、真假、来路、是不是赃物。稀罕东西（传家宝、古玩）用“伪随机保底”控制，前期少、后期多，不会一直不来。

### 5.3 白天
流言沿熟人关系一跳一跳地传，有延迟，越传越走样（已有系统，改为数据驱动）；你走到人旁边才听得到。NPC 按日程在镇上走动，你在街上也能遇见、搭话。

### 5.4 主线怎么嵌进去
现有序章、第一天、第二天的剧情改写成**有日期窗口和条件的故事卡**：比如“小丁带着孙记的米来当”在第 1 天上午触发，他走进门的方式和生成器的客人一样；“哥哥告别”在第 2 天中午。第 3 天以后，现有数据里埋的伏笔（第 4 天哥哥的信、第 5 天王山回来、第 9 天借条到期、第 32 天林嫂的当期）都放进日程，空白由生成器填。

### 5.5 玩家看不到的
概率、好感、人格标签、底价、未来的随机结果。看得到的：钱、物、合同、牌价（带来源和时间）、你亲眼看到和听到的事。人际关系的“可视化”（docx 第 17 条）用**人情簿**：谁送过你什么、你欠谁什么、上次见面说了什么、来信电报——没有数值条和爱心。

## 6. 当铺本身

- **铺子里能走动**：柜台（当铺的高柜台）、满当货架、库房、后门、楼上卧室。
- **交易时切到柜台特写**：沿用现有的验货（放大镜可返回看货）、模拟算盘＋口述报价、当票、账簿。
- **满当货架**：客人进门可以逛、可以只买一件；价格以当天市价为锚，人与人之间只有小幅差别（修 docx 第 7、14 条）。
- **活当**（docx 第 10 条）：当期内的东西你可以冒险先卖（赌一手），但合同和还原物的义务不消失；客人来赎时你得想办法把东西买回来。客人可以请求**续当**（付利息，或者拿新东西来顶）。
- **开局**（docx 第 8 条）：继承的满当旧货（各有来历）、几张还没到期的活当、一张保长的账单、爸的小银元、德字第一九六号。
- **多人议价**：同来的人可以帮腔、沉默、反对、改口；不是“说服加成”。

## 附：鉴定原则（主创定，2026-10-11）

鉴定是“对照图鉴、用朱笔圈出可疑处”的找不同，但**绝不直接给结论**。

1. **只写观察，不写判断。** 鉴定文字里不出现“怪、假、不对、可疑、和图鉴不同、和假批号一样”这类结论词，只写看到、摸到、闻到、称到的东西。
2. **图鉴写真品的感官特征，客人的东西用相近但不完全一样的说法，对不对由玩家自己对照。**
   - 图鉴：磺胺粉“微黄，开盒有一股淡淡的松香味”。
   - 真品可能写成：“微黄，松香味淡，像放久了。”
   - 仿品可能写成：“颜色发白些，闻着是泥土味，底下好像还有一点别的味道。”
3. **模棱两可是常态。** 真品也会因为存放、年份、磨损、受潮出现偏差的描述（灶房里放过的米带烟火气）；仿品也有仿得很像的地方。单看一处定不了，要用两三种方法互相印证（看＋称＋闻＋摸＋透光）。
4. **圈空了也不说“没有不同”**，只描述那块地方本身（“铁盒侧面，漆面平整，有两道细划痕”）。
5. **可以请人看**：花钱、花时间，托济生堂的陈叔叔看药、宝成银楼看金器。人家给的是看法不是判决，说法同样含糊（“这批货我说不好，你自己再掂掂分量”），偶尔还会看走眼。
6. **当场不揭晓。** 对错只在玩家自己做出决定（收、拒、当面指出）之后，通过后果体现：客人的反应、过几天被人识破、转卖时被压价。
7. 写作上：同一部位准备多条描述，按物品种子确定性地挑，避免玩家背答案。
