# 青溪镇 shared pixel assets (mockup stage 1)

All art is generated by code. Do not hand-edit the PNGs; change the generators and rerun:

```bash
cd /tmp/claude-0/-home-user-dehoudang/f413af39-a419-5ad7-b290-de5bfd493b6e/scratchpad/mockups
python3 gen_assets.py      # rebuilds everything in assets/ and assets/_preview/
python3 compose_A1.py      # rebuilds A1_town.png (1280x720) + A1_town_native.png (427x240)
```

| File | What it does |
|---|---|
| `pix.py` | Canvas class `Cv` (rect/line/ellipse/poly/dither/outline/blit/text), palette `C`, `font_mask()` for bitmap CJK, `scale()`, `contact()` |
| `gen_tiles_props.py` | Tiles, props, bridge parts and UI icons. `slab_field(w,h,seed,...)` makes a procedural flagstone pavement with no visible 16px grid |
| `gen_buildings.py` | Buildings in 3/4 top-down view, with sign text baked in. Also `roof_layer()`, `plaster()`, `lattice()`, `plaque()` and `gable_wall()` for making new buildings |
| `gen_chars.py` | 16x32 character sheets built from ASCII head and torso templates plus procedural legs. Add a character by adding an entry to `CHARS` |
| `compose_A1.py` | The A1 street scene. Shows the layering order, Y-sorting, shadows, colour grade and HUD; reuse it for other mockups |

## Conventions

- **Pixel scale.** All assets are native-resolution pixel art. Scale only by integers with NEAREST: x3 for a 427x240 view (crop the 1281 result to 1280), x4 for 320x180. Draw UI text at full resolution after scaling.
- **Palette.** `data/palette.json` (32 colours, names such as `C.wood1` and `C.indigo2`) plus a few extras in `pix.EXTRA`:
  - grass and foliage: `g0`–`g5`
  - water: `wa0`–`wa5`
  - warm 青石 stone: `st0`–`st5`
  - whitewash: `ww0`–`ww3`
  - roof charcoal: `rf0`–`rf4`
  - singles: `skinm`, `blush`, `lantern`, `lantern_hi`, `jade`, `jade_hi`, `postgreen`, `postgreen_hi`, `blue_hi`, `dirt0`–`dirt3`, `tabby0`–`tabby2`, `pink`, `flower`
- **Light.** Light comes from the top-left. Bevels are light on the top and left edges, shadows fall to the bottom and right, and drop shadows are soft dark ellipses under the feet (see `Scene.shadow`).
- **Outlines.** Characters and props have a 1px `dkbrown` (#1f1712) outline. The willow outlines only its crown, using `g0`.
- **Anchor.** Unless noted otherwise, every sprite is anchored at **bottom-centre**: its last row touches the ground. Y-sort by that ground y.

## chars/ (sheets 48x128)

## Scene recipe (`compose_A1.py`, native 427x240)

1. Ground:
   - `slab_field` street from y=108 to y=190.
   - `embank_*` row at `EDGE_Y=190`.
   - Water tiles below that, darkened slightly near the wall.
   - `back_roofs_strip` at the top.
2. The water lane between x=308 and x=348:
   - Bridge deck, step lines and curbs.
   - Arch face at the canal, plus its reflection.
3. Buildings left to right, ground line at `STREET_Y=112`:
   - Order: teahouse at x=-20, pawnshop 54, rice 176, pharmacy 242, police 346, post office 414.
   - Then an ambient-occlusion band along their bases.
4. Y-sorted sprites (characters, props, railings, boats), each with an ellipse shadow drawn before it.
5. Overhead markers.
6. `grade()`: saturation x1.18, warm lift, top-left light falloff. Per-pixel only, so the pixels stay crisp.
7. Scale x3 with NEAREST and crop to 1280x720. Then `hud()` draws at full resolution:
   - Wooden clock panel, top-right.
   - 今日 pressure ticker, top-left.
   - Lock tag over 警察所.
   - "E 进入德厚当" prompt.
   - Mockup label, bottom-left.
   - HUD text is the 12px bitmap font scaled x2 (`pixel_text`), which keeps it pixel-crisp.

## Using these assets in a Godot 4 "2.5D billboard" mockup

- **Import.** Disable mipmaps and use **Nearest** filtering. In Godot 4, set `texture_filter = TEXTURE_FILTER_NEAREST` on the Sprite3D, or set it project-wide under Rendering → Textures → Default Texture Filter = Nearest.
- **Characters.** Use a `Sprite3D` with `billboard = BaseMaterial3D.BILLBOARD_FIXED_Y`, `pixel_size = 0.0625` (1 px = 1/16 m, so a 16x32 cell is 1x2 m), `alpha_cut = ALPHA_CUT_DISCARD` and `shaded = false`.
  - Set `offset.y = 16` (or `centered = false`) so the feet sit on y=0.
  - Animate with `hframes = 3`, `vframes = 4`, `frame = row*3 + col`.
- **Buildings.** Use them as upright `Sprite3D` "flats" with no billboard: the facade quad faces +Z. Put each building's bottom edge on the ground plane. Optionally tilt the quad back about 10–20° so its roof reads from a 3/4 camera.
  - The A1 facade art already includes the roof drawn in 3/4, so for a true 3D roof, build a simple box with the `rf*` tile texture instead.
- **Ground.** Use a `MeshInstance3D` plane textured with `street_slabs_256x96.png`, or with tiles packed into an atlas. Set UV scale so 16 px = 1 m. Water is a plane using `water_*.png` with a little UV scroll.
- **Camera.** Use a perspective camera with FOV ~30–35° (or orthogonal), pitched down 35–45°. Add a soft `DirectionalLight3D` from the top-left. Shadows: use blob shadows (a dark ellipse decal or quad under each sprite), because Sprite3D cast shadows look noisy.
- **Renderer.** The Compatibility renderer (`--rendering-driver opengl3`) works under xvfb-run.

## A2 interior (德厚当 inside, `compose_A2.py`)

`python3 compose_A2.py` rebuilds `A2_pawnshop_interior_topdown.png` (1280x720) and `A2_native.png` (427x240), and exports the interior props below. `python3 make_A3.py` rebuilds `A3_counter_closeup.png`, which is the repo's `v03b_clean_counter.png` with a label added.

- **Room recipe.** The room is drawn as a Stardew-style box floating in a dark void. Side and front walls are seen only as their top strips; the back wall is the only wall face you see.
- **Geometry (native px).** Constants at the top of `compose_A2.py`: back wall rows 10–54, floor 55–149, front wall strip 150–156, door gap x 116–147, counter footprint rows 100–108 with height 22.
- **Occlusion.** The counter top covers native rows 78–86. Anything behind the counter shows only if its ground y is 77 or less. 沈如花 stands on a platform, so her feet are drawn at y=90 and only her head and shoulders show above the counter.
- **Layer order.**
  1. Floor (two `wood_floor` passes: the staff platform is darker) and a worn foot path.
  2. Back wall, then the shelves (`shelf_unit` with `fill_left`/`fill_right`), plaque and 财神 shrine, curtain door, drawer cabinet.
  3. Things behind the counter, then the counter, its rail and gate, then the items on the counter.
  4. The counter's cast shadow.
  5. Front-floor sprites, Y-sorted.
  6. Window light, then the wall strips, then the door sunbeam and dust, then the lamp and candle glows.
  7. `grade()`, scale x3, then dialogue box, HUD and label at full resolution.
- **UI.**
  - `frame_native()` is the Stardew-like wood and paper dialogue frame.
  - The portrait panel crops `art/portraits/<name>.png` to 48x52 and adds a name plate.
  - `ptext()` draws bitmap text with no vertical crop, so baselines stay aligned (Zen Hei Sharp 16px x2 for dialogue, 12px x2 for choices).
  - The HUD is A1's clock panel.
