## 启动与生成

使用 Godot **4.7.1.stable.official.a13da4feb**；云环境先执行 `source /workspace/.dehoudang-env/activate.sh`。

```sh
godot --path . -- --cards
python3 tools/napoleon/merge_drafts.py
GODOT=godot bash tools/run_ocean_tests.sh
GODOT=godot bash tools/run_legacy_smoke.sh
```

默认新局为土伦。拿破仑、原远洋、民国旧版分别使用 `user://cards/napoleon/`、`user://cards/ocean_pawn/`、`user://cards/`，`--save-dir=` 仍可指定独立目录。`DEHOUDANG_CAMPAIGN=ocean_pawn` 可进入原远洋版。

合并器按演出/伙伴→剧情/书→战场→地图顺序生成，重复运行应保持字节一致。运行时数据应修改相应生成器或源稿后再生成。现有美术继续作为占位，`data/hd/art_requests/C.json` 仅登记需求。

新地形复用现有注册贴图，虚空不生成地块。高墙、桅杆等地形的投影重叠时，统一按格心和已占用格的身体中心判定点击；全战场库逐格用真实鼠标输入验证，并覆盖大窗口下桅杆单位的身体点击。
