# 人试玩清单（卡牌版）

新档、种子自己记下。先开着新手指引走第 1–3 天，再同一套做法把指引关掉重走一遍。分辨率 1280×720。每条不是“感觉一下”，是看屏幕上有没有那件事。

对照合同 §0 九条红线和 §14.2 的界面项。有问题用 `bug_template.md`。

## 红线 1 · 免 AI 声明

- [ ] 玩家能读到的句子都像占位（开发版【稿】+ 一句干说明），没有人写成段的正文混在里面
- [ ] 没有把草稿样式当成正式字体排版交出去（正式正文还没由人写，这是预期，不是把占位当成品）

## 红线 2 · 确定性

- [ ] 同一粒种子，同样的点法，两遍钱、牌、日子一致
- [ ] 开着指引和关着指引，钱和牌一样（指引不改局）

## 红线 3 · 隐藏数值不上界面

- [ ] 口碑、风声只有文字档，没有点数、没有条、没有百分比
- [ ] 没有概率、权重、底价、真值、来路、耐心、本心的数字
- [ ] 轮盘扇区只看出大小，不写权重数
- [ ] 界面上任何地方都没有 `%`（含按钮、气泡、当票、小游戏、结算行）
- [ ] 可以有的数：钱、铜钱要几个正面、天数、人物属性点数

## 红线 4 · 规矩在戏里讲

- [ ] 没有单独弹出的“机制说明”窗
- [ ] 新规则是人物、告示、账簿批注在说话，不是说明书口吻

## 红线 5 · 鉴定只给观察

- [ ] 找不同、称重、铜钱、碎片、解密的结果里没有“真”“假”“仿”“赝”，也没有 true/false/fake/real 这种判词
- [ ] 小游戏只让你看见裂纹、轻重、花纹，不告诉你这件东西是不是假的

## 红线 6 · 史实措辞

- [ ] 日方扶植的政权写了“伪”字
- [ ] 1945 写成抗战胜利，1949 写成解放，抗战按十四年
- [ ] 1950 年代没有随机惩罚牌、斗争会、暴力场面

## 红线 7 · 测试（给跑清单的人）

- [ ] `tools/run_card_tests.sh` 与 `tools/run_legacy_smoke.sh` 没有 `SCRIPT ERROR` / `ERROR` / `WARNING` / `FAIL:` / 泄漏
- [ ] 每条清单最后一行是 `CARDS TEST PASS <名字>`

## 红线 8 · 每个机制都有新手指引

- [ ] 一个机制第一次出现时，有一步亮起来：人物开口、高亮对应的东西、一句气泡说现在可以做什么
- [ ] 没有“还没教过就突然能用”的按钮或玩法
- [ ] 教过的能在档案簿“规矩”栏再看，F1 帮助里也能再看
- [ ] 设置里关掉新手提示之后，什么都不亮，但该做的事都还能做
- [ ] 关掉再开，同一串操作，钱和牌不变

## 红线 9 · 打烊永远可用

街头、牢房、每种面板开着、小游戏开着、留牌满、钱不够、月初还没转本月运势，都要看一遍。

- [ ] 上面每一种局面里，“打烊 · 下一天”都按得到；面板或小游戏开着时，关掉就回到牌桌，按钮还在
- [ ] 还有东西没处理时，先弹出确认面板，把每一行会怎样列出来；确认后按“没理会”结算，不会被某一张牌挡住
- [ ] 确认面板列的每一行，和第二天牌桌上看到的结果对得上（谁走了、什么过期、牢里是不是多一夜，和那一行说的一样）
- [ ] “回去看看”不结算，还停在原来这一天
- [ ] 没有任何东西因为“时间到了”自己进入下一天、自己关面板、自己替你选出价

## 指引不挡操作

- [ ] 气泡亮着时，仍能点到手牌、按钮、键盘
- [ ] 指引那一层点得穿（点下去是牌和按钮，不是一块挡板）
- [ ] 一步做完会走，不会永远盖在屏幕上

## 键盘能走完一天

- [ ] Esc：有面板就关面板，没有就开暂停；暂停里再按 Esc 能回来
- [ ] Enter、Space：对话框 / 当前按钮能推进（和鼠标点同一件事）
- [ ] 1–9：选对应的手牌（第 1 张是最左边，金色牌应在最左）
- [ ] Tab：焦点在面板里移动，不丢到屏幕外
- [ ] F1：打开帮助；再按 F1 或 Esc 关掉
- [ ] 不靠鼠标，能从开局走到打烊、过夜、日结

## 界面（§14.2 里给人看的那些）

- [ ] 金色牌一眼能认（颜色和位置，不用读完说明）
- [ ] 草稿样式明显，不会把【稿】看成已经写完的正文
- [ ] 像素是整数倍，图不发糊、不出现半个像素的缝
- [ ] 面板落在中间一块里，不超出大约 1100×640，不压死顶栏和手牌
- [ ] 顶栏、左栏、右栏、手牌互不重叠
- [ ] 钱、日子、天气能读完，不被裁掉

## 画面与对话

人看屏幕，不交截图。一张牌打出以后，主要看画面里的人和对话框，不是只看牌面。

- [ ] 打出一张牌之后，人上场（站在这一出该站的地方）
- [ ] 对话一句一句往下说
- [ ] 回话就是这一出的选择
- [ ] 三档价、天数、铜钱数以外没有数字
- [ ] 口碑、风声只有字
- [ ] 抽屉能打开也能合上，柜台上的热点都点得着
- [ ] 同一天里能看出白天、黄昏、夜里
- [ ] “打烊 · 下一天”在抽屉开着的时候，在抽屉上面，照样按得到
- [ ] 字不糊（整数倍像素，不缺半个字）

## 一天的路径（Mock 或真局都可以）

- [ ] 开月过场能关掉，本月运势能转完，然后才是早上
- [ ] 柜台：能看货、出价、结束这一张牌
- [ ] 小游戏：能做完并回到柜台，没有判词
- [ ] 打烊：任何时候都能按“打烊 · 下一天”；还有牌没处理就先列清单，确认后按没理会进夜里（不会被牌拦住）
- [ ] 夜里能选一件事，然后是日结，然后下一天早上
- [ ] 月底能看到结算并进入下一程（真引擎未接上时，只要求 Mock 能走到月底）
