主创看了纯文字牌桌版的试玩：“不对吧，你这个为啥没有画面。我想的就是深空当铺那种二维的，然后牌在最下面跟炉石传说一样，旁边有一些能打开关闭的功能。主要还是看画面跟别人对话，不是打牌。打牌是玩法，对话是载体。”编排按这个方向重做了这个网页原型，主创看完说“不错”。它就是合同 1.3「画面与对话」的样子（`docs/cards/CARDS_INTERFACES.md` §1.2、§4.7.24、§7.11；`docs/cards/DESIGN_cards.md` §九.6）。

## 怎么看

1. 打开 `scene_demo.html`，点“开张”。
2. 把最下面的一张牌拖到门口（或点一下再点“打出”）：这个人走进门、开口说话；点对话框继续；话说完，下面是你的回话。
3. 来当来卖的可以先“拿放大镜细看”（小游戏），再出价。
4. 左右边缘的标签打开抽屉；柜台上的账簿、黄历、钱匣、档案簿也能点。
5. 随时可以按“打烊 · 下一天”：还有没处理的会先列给你看，再按一下才关门。
6. 一天里处理的牌多了，画面从白天变黄昏；打烊后是夜里。

## 哪些只是网页原型的做法，**不要照搬**

- **手机竖屏**：正式游戏只做 PC 1280×720。
- **JS 引擎与规则**：原型里的引擎（发牌、价钱、两个礼拜 14 天、结账周期……）是为了能玩起来临时写的，和合同、真引擎（G01–G06）不是一回事；规则一律以合同为准。
- **文字**：原型里的台词、旁白、牌名、人物名、提示句都是**占位**（AI 写的，或从牌的描述机械拆出来的）。不许拷进 `data/cards/text/**`，也不许当成 `brief` 的范本；正式正文由 A 写。
- **图**：原型用的是 v0.4.2 的旧图（AI 产出）和几张派生图，只是占位；不许拷进 `art/cards/**`。正式美术见 K12 的 `ART_SPEC.md`。
- **网页做法**：CSS 缩放、`localStorage` 存档、网页里的“知道了 / 关掉指引”按钮（正式的新手指引不挡鼠标，§7.10.7）、悬停把牌放大 1.34 倍（正式只许整数倍：悬停是抬起，选中才放大到 288×400）。
- **坐标**：原型的坐标按浏览器窗口算；正式坐标以合同 §7.11.2 的 `CardLayout` 为准（例：“打烊 · 下一天”正式在 (1020, 556)，原型在 (1020, 478)）。
- **标签与热点的摆法**：原型左边 3 个标签、右边 5 个（“规矩”在右边），客人的东西能称的时候柜台上还会多一个戥子（称分量）；正式是左右各 4 个、“规矩”在左边，柜台上的热点是 9 个、没有戥子（合同 §7.11.2、§7.11.9）。
