## 〇、总览

### 一句话

1938 年，江南小镇青溪镇，你接手了德厚当。每天进门的人、街上出的事、命运的转折都是随机抽来的；当不当、给不给、帮不帮，由你决定。一个月是一关，打完跳一年，时代变了牌也变了；1949 年解放后，你按这些年攒下的东西改行，走进新的分支。

### 三条原则

1. **贴近生活，不分黑白。** 选项不标好坏，结果有得有失。日常开销（米、煤、看病、学费、人情、过年）都是牌。“本心”藏在后面，只影响你能走哪些路。
2. **参考大富翁。** 随机的命运牌；钱不够就一样样抵押家当，押光了流落街头碰运气；坐牢可以花钱打点、找人保；手头宽裕可以置产。
3. **参考《苏丹的游戏》。** 胡二每周送来一张限期七天的“条子”；大事件上有空格，把人物牌、东西、钱放进去，按属性掷铜钱定成败；一部分牌可以留在手里，想用的时候再打。

### 整体结构

```
当铺年代：每关一个月，打完跳一年（12 关）
  1938 ─ 1939 ─ 1940 ─ 1941 ─ 1942 ─ 1943 ─ 1944 ─ 1945 ─ 1946 ─ 1947 ─ 1948 ─ 1949
  └──── 首发（抢先体验）：三大关 ────┘
                                                                      │
                                                            解放·选新行当
                                                                      ├─ 信托商店/旧货店
                                                                      ├─ 茶馆
                                                                      ├─ 中药铺
                                                                      ├─ 杂货铺
                                                                      ├─ 修理铺
                                                                      └─ 教书/代写
                                                     各分支到 1956 年公私合营收尾
```

| 层级 | 是什么 |
|---|---|
| **一天** | 发一手牌（人物、事件、消息、偶尔命运牌），一张张处理；晚上选一件事做，结算。 |
| **一周** | 每周一胡二送来一张条子，七天内办完。生活牌每周一两张。 |
| **一关（一个月）** | 开场看时局和本关目标；月底结账（抵押利息、当票、生活开销）；打完跳一年。【v1.1】每关开头转一次命运轮盘，定这个月的运势（§九.1）。 |
| **当铺年代（12 关）** | 1938–1949，每年一关。时局推进，牌库整套更换，货币和物价跟着变。 |
| **解放后** | 按攒下的人脉、钱、档案簿和本心，选一个新行当；进入该行当的新牌库，到 1956 年收尾。 |
| **首发** | 1 月抢先体验：前三关（1938、1939、1940）。之后按年更新到 1949；解放后的分支作为大更新。 |

本文档的数字都是起始值，标着 **【待调】** 的要在原型里试玩后调。

## 一、一天怎么过

```
早上 · 发牌  →  白天 · 处理  →  晚上 · 夜牌  →  结算
```

【指引】这一天里的每样东西，第一次碰到时都由人物在戏里教一遍（第 1 天哥哥在柜台教，§九.4）。

【10-13】**节奏由玩家把握**：画面右侧中下永远有“打烊 · 下一天”按钮，任何时候都能按（街头、牢房里也一样）。手上还有牌没处理时，先弹确认、列出会发生什么；确认后没处理的按“没理会”结算。没有真实时间倒计时，不会自动跳天（§九.5）。

【画面】打出一张牌，这件事就在柜台的画面里“演”出来，你在对话框里回话（§九.6）。

- **早上 · 发牌**：看今天的告示（天气、集市日、时局），发今天的牌。【v1.1】告示上还有当天的黄历宜忌（§九.2）。
- **白天 · 处理**：按任意顺序处理手里的牌；能留的牌可以先留着。【v1.1】金色角色牌排在手牌最前面，当天必须处理（§九.3）。【10-13】什么时候打烊由你定：按“打烊 · 下一天”，没处理的先列给你看、确认后按“没理会”结算（§九.5）。
- **晚上 · 夜牌**：三张夜牌里选一张做。
- **结算**：当票倒计时、留牌过期、条子剩几天、下一天的牌库按状态调整。

### 每天发什么牌 【待调】

| 牌 | 每天几张 | 说明 |
|---|---|---|
| **人物牌** | 3–4 张 | 今天进门的人。可以拒绝，但不能跳过。集市日多一张，下雨少一张，口碑高好客人多。【10-13】打烊时还没接的人走掉，个别人记仇（§九.5）。 |
| **事件牌** | 1 张 | 街上的事、时局的事，必须处理。【10-13】打烊时没处理的按“没理会”的结果结算（§九.5）。 |
| **消息牌** | 0–1 张 | 行情、线索、流言、信、电报；很多会变成档案簿里的碎片。 |
| **命运牌** | 随机 | 大约每三四天一张；风声大、时局乱时更常见。好坏都有。【10-13】没处理同事件牌（§九.5）。 |
| **生活牌** | 每周 1–2 张 | 米缸见底、煤、看病、孩子学费、婚丧人情、过年。 |
| **条子** | 每周一 1 张 | 胡二送来，限期七天（见“条子”一节）。 |
| **主线牌** | 固定日子 | 到某天、或口碑风声到某档才出现。【v1.1】主线人物在主线节点上以**金色角色牌**出现（§九.3）。 |

### 夜牌（三选一）【待调】

| 夜牌 | 做什么 |
|---|---|
| **整理库房** | 货架上的东西擦洗归置，卖的时候稍好出手。 |
| **对账** | 看清这个月是赚是赔；有时翻出账上的问题（消息牌）。 |
| **后门收货** | 夜里有人敲后门，便宜，但来路不明，风声会动。 |
| **发电报** | 主线专用（第三天起），给远方的哥哥或别的人。 |
| **回家吃饭** | 一家人吃顿饭；抵掉一张生活牌的坏处，或者得到一张家人的消息。 |
| **早点睡** | 明天多发一张人物牌。 |

### 示例：1938 年 3 月第 9 天

- **早上**：告示说今天下雨、不是集市日。发牌：人物 3 张（林嫂、孙福、一个外乡人），事件 1 张（“警察挨家查良民证”），消息 1 张（周妈说：王山昨晚在码头出现过）。手里还留着一张“马万利欠你一次”。条子剩 3 天：要 60 蚨。
- **林嫂来当金簪**：你点开金簪，这次随机出的小游戏是“称分量”——用戥子称，比她说的轻一点点。线索是“分量差了一钱，像是补过”。你出“公道价”，她接了，得到一张当票（15 天后到期）。
- **查良民证**：事件上有两个格子：放“良民证”这张留着的牌就直接过；你没有，只好放 10 蚨和小丁（胆量 2）进去，掷 3 枚铜钱，要 2 个正面——掷出 1 个。警察记下了你的名字，风声上一档。
- **孙福来买字画**：你从货架挑了一幅，报“厚道价”太低了，你改报“公道价”，他还价，成交，进账 45 蚨。条子的钱凑够了。
- **外乡人求当棉袄**：棉袄不值钱，他说孩子病了。你可以压价收、厚道价收、白给他几个钱、或不收。你白给了 5 蚨——本心不显示，但档案簿里多了一页“外乡人”。
- **晚上**：选“回家吃饭”，抵掉了周末那张“煤用完了”的坏处。结算：当票 14 天、条子 2 天、明天牌库里查铺的牌多了一张（风声上去了）。

## 三、核心机制

### 1. 柜台：当、卖、买、赎

- **来当 / 来卖**：客人拿来一件东西，说个价。你可以点开东西做**鉴定小游戏**（也可以不做），得到线索；然后出三档价之一：**压价 / 公道 / 厚道**。客人接受、还价或走人（他心里的底线藏着）。来当得到当票，来卖东西直接归你。
- **来买**：买家要某一类东西。你从货架挑一件、报三档价，他还价或走人。**货架上的东西只能这样卖出去**，没有一键卖掉。
- **来赎**：当票到期时，当户可能拿着钱来赎。照规矩还；或者刁难加价（钱多了，口碑和本心掉）。东西要是被你提前卖了，就得赔钱或者去买回来。
- **求助 / 打听**：不为买卖，为借钱、托事、问消息。帮、不帮、告发，都有得有失。

### 2. 鉴定小游戏（随机出）

| 小游戏 | 怎么玩 | 适用 | 首发 |
|---|---|---|---|
| **找不同** | 左边柜上这件、右边图鉴：自己在东西上点出不一样的那一处，再说它是“旧痕”还是“不一样”；点空了、说错了都照记（主创 10-25 改）。 | 瓷器、首饰、书画、铜器 | ✓ |
| **吹银元** | 柜上有铺子自己的两枚样洋（足银的、哑板）。点哪枚吹哪枚，余音画成一道线；听完自己说客人这枚像足银的还是像哑板（一摞的一枚枚标响或哑）；两枚相碰，里面有哑的碰声就闷（主创 10-25 改）。 | 银元、银器 | ✓ |
| **称分量** | 拨砝码、拖秤砣，自己看定盘针平没平，按“看星”后自己数星读出分量，再和客人说的比：对得上、轻一点点、轻了不少、反倒重了。游戏不替你读、不替你比（主创 10-25 改）。 | 金银、米、药材 | ✓ |
| **拼碎片** | 看撕口和墨线把碎纸拼回去；拼好以后自己看骑缝印两半对不对得上，在墨接不上的拼缝上打个叉（主创 10-25 改）。 | 文书、书画、当票 | ✓ |
| **对印章** | 转动印章，和账上、图鉴里的旧印对齐比较。 | 文书、字号、书画 | |
| **闻、摸** | 几段描述对着挑（樟木味、霉味、新漆味……）。 | 衣物、木器、药材 | |
| **解密** | 电报码、暗信、账本暗语；主线专用。自己翻真正的电码本找码抄词；洇了的字两种读法都查一查，挑说得通的；加了码的先拿本号对出加了几；抄错了就照错的记（主创 10-25 改）。 | 主线 | ✓ |

> **规矩**：小游戏做得好，线索清楚；做得差，线索含糊。**永远不直接告诉你真假**——只给观察（“分量差了一钱，像是补过”），由你自己判断。客人有耐心，拖久了他会改价或者走人。**看出来的才算数**（主创 10-25：“你那个鉴定不能只是点点点，要玩家看出来才算数”）：你说的就是你记下的，看走了眼也照记；说中了客人认，冤枉了客人不服。

### 3. 条子（胡二，每周一张）

| 类别 | 要什么 | 怎么办 |
|---|---|---|
| **要钱** | 交一笔摊派、“孝敬”。 | 放钱；或放人情牌、口才高的人去讲价降档 |
| **要货** | 指定一类东西（米、布、药、铜器）。 | 放货架上合适的物品牌；没有就得去收 |
| **要人** | 出夫、修工事、凑壮丁名额。 | 放一张人物牌（这个人这周不能用，可能回不来）；或花钱顶替 |
| **要消息** | 让你说出谁常来、谁可疑。 | 放消息牌（会伤到那个人，档案簿那页可能断掉）；或者编一个（掷胆量） |

每类分四档：**小 / 中 / 大 / 要命**。档位随时局和风声上升【待调】。办不成按档位吃亏：罚钱 → 查封三天（不发人物牌）→ 拿走一件家当 → 被抓。可以“拖一拖”：期限加三天，但条子升一档。

### 4. 放格子、掷铜钱

- 条子、大事件、命运牌、牢房都有几个**空格**，每格标着要什么：钱、东西、人（某项属性）、证件、人情。
- 人物有四项属性：**眼力**（看东西、看人）、**口才**（讲价、说情）、**门路**（关系、办事、消息）、**胆量**（冒险、硬顶）。
- 放进去的人和东西加起来，**每点属性给一枚铜钱**；一起掷，正面数够了就成。铜钱数看得见，成功的机会自己估（不显示百分比）。
- 放进格子的人当天不能再用；有的事件会让人受伤、被扣、离开。

### 5. 留着的牌

- 一部分牌不用当天处理，可以**留在手里**，想用的时候再打：人情（马万利欠你一次）、证件（良民证、孙府介绍信）、硬货（一根金条）、把柄（某人的秘密）、空白当票、主线信物。
- 手里最多留 5 张【待调】；有的会过期（人情放久了不灵）；有的留着本身就有风险（把柄、来路不明的东西被查到会出事）。
- 留牌是在牢房、条子、大命运牌这些关口保命的主要手段——和大富翁的“出狱卡”一个道理。
- 【v1.1】金色角色牌**不能**留到第二天（§九.3）。

### 6. 命运牌和大命运牌

- **命运牌**随机发，大约每三四天一张【待调】；风声越大、时局越乱，坏的越多。好的：拾到钱袋、远亲寄钱、米价跌、老主顾介绍生意。坏的：罚款、查封三天、征用、空袭、失火、被诬告、币制改革。
- **大命运牌**在你快输的时候出现，给一次翻身的机会：
  - 触发：钱不够付条子且家当快押光；被抓进牢房；风声到了最高一档；流落街头超过几天。【待调】
  - 它不一定救命，是一次**大赌**：成了能还清抵押、出狱、压下风声；败了直接坠底。比如“陌生人出大价钱请你保管一箱东西七天”“孙老爷要人作保”“有人高价买你的老宅”“一张去上海的船票”。
  - 每关最多出现两次，同一种危机只给一次。【待调】
- 【v1.1】快输的时候，大命运牌**改成转一次“大轮盘”**，扇区更极端：翻身／平安／坠底（§九.1②）。
- 【10-13】大命运（大轮盘）当天没处理就作废——这次翻身的机会错过了（§九.5）。

### 7. 抵押、流落街头（破产阶梯）

| 一步步往下 | 怎么回事 |
|---|---|
| **① 钱不够** | 先卖货、拿货抵。 |
| **② 抵押家当** | 一样一样押出去换现钱，每月付利息，月底有钱就能赎回。押出去的东西会让你少一样本事：首饰柜 → 不能收首饰；库房 → 货架变小；柜台 → 每天少一张人物牌；老宅 → 一家人搬进铺子，生活牌变多；铺面 → 押出去的那个月还能开，月底赎不回就没了。 |
| **③ 流落街头** | 铺面没了，换成“街头”牌库，每天 3 张：乞讨、打零工、摆地摊、替人写信、跑腿、当掉随身东西、赌一把。熟人有的帮你，有的躲你。 |
| **④ 爬回来** | 攒够钱赎回铺面，重新开张；之前押出去的家当按原价赎。 |

### 8. 被抓、打点、结局

- 被抓的原因：风声到顶；“要命”档的条子没办成；某些命运牌（被诬告、窝藏）。
- 被抓后进**牢房**事件：格子可以放钱（打点）、人脉（保人）、留着的牌（人情、介绍信、金条），再掷铜钱。成了就出来，代价是钱、人脉或家当；不成，这一局结束。
- 结束后可以从这个月开头重来（存档按月）。
- 【10-13】牢房没处理就在牢里多待一天（铺子关门、不发人物牌）；连续 3 天【待调】没出来按打点失败结算，这一局结束，可以从本关开头或续玩点重来（§九.5、附 9）。

### 9. 口碑、风声、本心

| | 怎么显示 | 影响什么 |
|---|---|---|
| **钱** | 明着显示 | 一切买卖、条子、抵押。开局 340 蚨【待调】。货币改了会换算（见年代表）。 |
| **口碑** | 五档文字（“没人知道”→“老字号”） | 来的是什么人、客人肯出多少、买家多不多。 |
| **风声** | 五档文字（“平静”→“要抓人了”） | 查铺、命运牌里坏牌的比例、条子的档位；到顶就被抓。 |
| **本心** | 不显示 | 大命运牌出现哪几张、主线往哪走、解放后能选哪些行当、结局文字。【v1.1】本心低时求到的签更凶（§九.2）。 |

### 10. 人脉

- 帮过、结交过的人会变成**人脉牌**，常驻在桌边：能放进格子出力，也带被动效果。
- 人脉不是只有好处：马万利让条子降一档，但风声每天涨；王山胆量很高，但跟他走得近，查铺的牌会变多。
- 人脉会离开：被抓壮丁、搬走、死于空袭、和你翻脸。跨年时可能变了身份。

### 11. 档案簿：碎片化叙事

- 每个人一页。每次遇到他，就补一块碎片：他当了什么、说了什么、别人提起他的话、报纸剪报、当票上的字、一封信。
- 跨年时补“一年后”：林嫂当的金簪一直没人来赎，一年后的消息告诉你为什么。
- 有的碎片只有你当时做了某个选择才拿得到；把人交出去，那一页可能就此断掉。
- 一页补齐，解锁这个人的结局牌或人脉牌；整本档案簿的进度影响解放后的选择。
- 【v1.1】金色角色牌没处理，档案簿那一页留下缺口（§九.3）。

### 12. 牌库怎么变（随机从哪里来）

- 每天的牌从几个牌库里抽：人物牌库、事件牌库、命运牌库、消息牌库、生活牌库。每个牌库里每张牌有权重。
- 权重随状态变：口碑高好客人多；风声大查铺和坏命运多；集市日买家多；下雨人少；时局（年份）决定哪些牌在库里。
- 整套用现有的 GameJev 生成器和确定性随机（同一个存档、同样的选择，抽到的牌一样），方便测试和平衡。
- 主线牌、条子、生活牌按日程插入，不完全靠抽。
- 【v1.1】本月运势（§九.1①）也调权重；求到的签“准”，靠的就是这套确定性随机（§九.2②）。

### 13. 置产（可选，第二个更新再做）

手头宽裕可以盘下隔壁铺面、买一间房收租，像大富翁买地。房子每月有租金，也能在破产时抵押；空袭、征用可能让它没了。

## 四、一关（一个月）

- **开场**：时局过场（这一年发生了什么），本关牌库换上，本关目标：1 个主线目标 + 2 个可选目标（比如“月底前赎回首饰柜”“补齐周妈那一页”）。【v1.1】开场转一次命运轮盘，定这个月的运势（§九.1①）。
- **每周一**：胡二送条子。**每周**：一两张生活牌。
- **月底结账**：付抵押利息、清点当票、生活开销、结算本关目标；给一个评语（不是分数，是街坊怎么说你）。
- **跳一年**：没人来赎的当票全部满当，东西归你；档案簿补“一年后”；物价、货币按新一年换算；部分人脉离开或变了身份；新面孔进入牌库。
- 存档：每关开头自动存一份，失败可以从这个月开头重来。

## 六、解放后：选新行当

> 1949 年那一关以解放收尾。这时候银元重新成了硬通货，当铺在新的利率规定下难以为继，陆续歇业；一些城市开设了人民银行的小额抵押贷款机构和国营的信托商店（旧货寄售）。你要选一个新行当。

### 能选哪些，看前面攒下的

- **人脉**：周妈那条线开得出茶馆，陈文庭那条线开得出中药铺，李敬之那条线能去教书。
- **钱和家当**：赎回来的铺面、置下的房，决定新行当的开局本钱。
- **档案簿**：补齐的人越多，新行当里认识的人越多。
- **本心和风声**：前面为维持会办事太多，有些行当选不了，或者开局带一张“历史问题”牌（留着的牌，会在某些时候被翻出来）。

### 分支

| 新行当 | 和前面的关系 | 新牌、小游戏 |
|---|---|---|
| **信托商店 / 旧货店** | 离当铺最近，鉴定估价都用得上；收的是寄卖、旧货。 | 沿用鉴定类小游戏；寄卖牌 |
| **茶馆** | 周妈线。人物牌变成茶客，消息牌最多，最适合碎片叙事。 | 泡茶、记茶钱、听书 |
| **中药铺** | 陈文庭线。验药材、抓方子。 | 验药材、称分量 |
| **杂货铺** | 凭票、配给的日子。 | 记账、算账 |
| **修理铺** | 修表、修钟、修收音机。 | 拆装、修理 |
| **教书 / 代写书信** | 李敬之线。牌以人物和消息为主，替人写信读信。 | 识字、代写 |

- 档案簿接着记：老面孔在新行当里重新出现，换了身份。
- 条子不再是胡二，换成新时代自己的“任务”和“通知”；风险牌、生活牌换成新年代的内容。
- **收尾**：1956 年初公私合营：各行当以“公私合营”收尾，比如“德厚当改为公私合营信托商店，你成了私方人员”，结局文字不作褒贬。1950–1953 年的土地改革、“五反”、统购统销只作为政策和经济事件来写（查账、乡下的当户不再来、凭票买粮），不做成惩罚玩家的随机命运牌。

### 结局

- **中途**：被抓且没能打点出来——这一局结束（可从本月开头重来）。【10-13】也可以从续玩点重来；牢房连续几天没处理也算没打点出来（§九.5）。
- **当铺年代结局**（1949）：按钱、家当、口碑、本心、档案簿，给“德厚当这些年”的结局文字。
- **分支结局**（1956）：每个行当各自几种结局。

#### 一句话

**对话是载体，打牌是玩法。** 屏幕上大部分是柜台的像素画面；你从手里打出一张牌，这件事就在画面里“演”出来：该来的人走进门、站到柜台前，在对话框里一句一句说，你的选择是“回话”，结果也是对话。牌决定今天发生什么、你能用什么；画面和对话让你看见、听见这件事。

#### 画面是什么样

| 部分 | 在哪 | 是什么 |
|---|---|---|
| 场景 | 整屏（320×180 的像素画，整数 4 倍铺满 1280×720） | 德厚当的柜台：两扇窗、敞着的门（门外是街）、柜台面、柜台上的工具；白天 → 黄昏 → 夜里；街头、牢房、城隍庙等换背景 |

| 打烊 · 下一天 | 右侧中下 | 永远在、永远能按（§九.5） |

#### 一张牌从手里打出到演完

1. **打出**：把手里的一张牌拖进画面（门口或柜台），或者点它一下（放大看）再点“打出”。
2. **上场**：这张牌要的人上场——客人从街上走进门、立绘滑到柜台前；事件里的人站在门口；有的牌换背景（后门的戏换成烛光、城隍庙、牢房）。来当来卖的人把东西摆上柜台。
3. **说话**：对话框里一句一句说：谁来了、他说什么、旁白交代这件事。点一下继续，“跳过”直接到最后一句。
4. **回话**：话说完，下面列出你能做的事，都是“回话”：来当来卖是“压价 · 多少钱 / 公道 · 多少钱 / 厚道 · 多少钱 / 不收 / 拿放大镜细看”（金额由引擎给）；求助是“帮 / 不帮 / ……”；条子是“交钱 / 讲价 / 拖一拖……”；每件事都有一句“请他先等等，回头再说”。选了哪句，那句就是你说的话。
5. **检定**：要放格子的，格子出现在柜台上；把头像、人脉、留着的牌拖进去（钱用格子上的加减），回话里多一句“掷铜钱 · N 枚 · 要 M 个正面”；铜钱在柜台上翻，结果也是对话。
6. **收场**：成了、没成、客人还价、走人，都用对话说出来；人出门、道具收走，画面回到空柜台，手里少了这张牌。
7. 任何时候都能先放一放（“回头再说”、Esc），也能直接按“打烊 · 下一天”（§九.5）。

## 附：实现时的理解（编排补充，**不是主创原话**；具体做法以 `CARDS_INTERFACES.md` 为准）

以下几处 v1/v1.1 没说到细节，为了 38 条线能同时开工，编排先这样定；主创改口时以主创为准，合同跟着改。主创 2026-10-13 回复“同意你说的九点”（PDF v1.2 第九节那九条），原来标【待主创确认】的都改成 **【主创已确认 10-13】**；同一天主创又定了“打烊 · 下一天”（§九.5），第 1 条跟着改，第 18 条是它的落地细节；当天晚上定了“画面与对话”（§九.6），第 11 条的“左下角教的人”跟着改，第 19 条是它的落地细节。

1. **“不能跳过”和“不处理他就走了”怎么同时成立**【主创已确认 10-13；同日按 §九.5 改】：金色角色牌排在最前、提醒你，**可以不处理就打烊**——打烊时先问一句（人写的话），你确认后他走掉，按“没理他”结算（合同 §10）。~~普通人物牌、事件牌、命运牌、牢房牌没处理完不能打烊~~——10-13 起取消：所有牌都和金色牌一样，“打烊 · 下一天”永远能按，还有牌没处理就先列清单、确认后按“没理会”结算（§九.5、合同 §7.4.7）。“不能跳过”落成：每张牌都会有个了断——你处理了，或者打烊时按没理会算；拒绝也算处理。
2. **签为什么“准”**：求签时引擎按种子先算出接下来几天会抽到的牌，从里面挑一两张写进签里，再把这几张“钉”在那一天，到那天一定发（这张牌到时候条件不满足，就换一张同样征兆的）。所以签永远是准的；签文只说征兆（“官面”“水边”“远方来信”），不说是哪张牌（合同 §9.3）【主创已确认 10-13】。
3. **本心低时签更凶**：从接下来几天的牌里挑写进签里的那一两张时，本心越低越挑坏的；签的等第跟着挑出来的牌走。签仍然准，只是你更容易先听到坏消息（合同 §9.3）【主创已确认 10-13】。
4. **黄历“照着做”**：做了当天宜的事、并且没做忌的事，日结时给一点小好处；没照着做什么也不发生（合同 §9.4）。
5. **大轮盘和原来的大命运牌**：触发条件和每关次数上限照 v1。手里出现一张“大命运”牌，处理它就是转大轮盘；扇区分翻身／平安／坠底三类。v1 里的那几个“大赌”（一箱来路不明的东西、孙老爷要人作保、有人高价买老宅、一张去上海的船票）放在翻身或坠底扇区里，作为转到以后发到手上的牌，平时不会随机发出来【主创已确认 10-13】。手里那张“大命运”当天没处理就作废（§九.5）。v1 §三.9 说本心决定大命运出现哪几张：扇区可以带条件，本心不够的那几段这次不上盘（合同 §4.7.17）。
6. **押一张留着的牌**（庙会、赌摊）：转到坏扇区这张牌没了，转到平常或好的扇区还给你（做法【主创已确认 10-13】，细处【待调】）。
7. **香案上的人脉**：人脉放上香案和放进格子一样，当天不能再用，不会被消耗；香火钱花掉；留着的牌用掉（做法【主创已确认 10-13】，细处【待调】）。转之前打烊的，香案上的东西都还给你（§九.5）。
8. **鉴定小游戏的时间**：小游戏会花掉“钟点”，从客人的耐心里扣（v1“拖久了他会改价或者走人”）。一天有个钟点只是显示，不会因为钟点到了强行打烊【待调】；也没有任何真实时间的倒计时（§九.5）。

18. **“打烊 · 下一天”怎么落地**（§九.5 的细节，编排定，主创看过可以改；合同 §7.4.7）：引擎的“打烊 · 下一天”除了局终，任何时候都能按，每按一次往前走一步——白天 → 夜里（夜里按 = 今晚不选夜牌）→ 日结 → 第二天早上；开月时本月运势还没转，就替你转（香案上已经放的照算）。按之前先给一张清单：每样没处理的东西会怎样，都是人写的话。没理会的后果写在每张牌上（数据里的 `on_expire`），没写、带检定的当没过；个别人记仇也写在那张人物牌上。从任何能到的状态连按最多八次，一定进到下一天或这一局结束——这条有自动测试守着（随机乱点、随机打烊，上千局不卡死）。
19. **画面与对话怎么落地**（§九.6 的细节，编排定，主创看过原型说“不错”；合同 §1.2、§4.7.24、§7.11）：画面是 320×180 的像素场景整数 4 倍铺满 1280×720，上面一层是界面（HUD、对话框、手牌、头像与人脉、两侧标签与抽屉、打烊按钮、叠层）。一张牌“怎么演”（谁上场、站哪、换什么背景、柜台上摆什么、先说哪几句、选了以后接哪几句）大部分按牌的种类有默认做法，不用写；要特别演的牌在数据里写一个“演出块”，只写谁上场、站位、道具、效果和对白的**键**，对白的字仍由人写。白天到黄昏看今天发的牌处理掉了多少（六成以上算黄昏【待调】），打烊后是夜里——这只是画面，不影响任何规则。手机竖屏只是网页原型的做法，正式游戏只做 PC 1280×720。
20. **鉴定“看出来才算数”怎么落地**（主创 10-25 原话“你那个鉴定不能只是点点点，要玩家看出来才算数”，编排定，主创授权“你自己决定”；合同 §8、附录 H）：证据由隐藏真值确定地生成，真货假货“数量一样”（每件固定三处痕迹、一摞几枚都一样），只有样子不同；玩家自己下判断，判断就是记下的观察，引擎不按对错过滤；清晰度只看过程（翻没翻图鉴、比没比样洋、秤压没压平），只决定旁白的口气；对错只进引擎的私账——来当来卖的客人第一次被鉴定时“说破”：说中了真破绽客人让价，冤枉了客人他不服、耐心少一截、底价抬高（不扣口碑），一个客人只说破一回；眼力多给几笔墨、大些的镜片、多吹几次，懂行的人脉给全图例、能对着光看，店里的猫照旧加一。主线的拼碎片、解密做对做错这一版不分剧情，只影响记下来的观察。
21. **肉鸽 v1 怎么落地**（主创 10-25 原话“能不能加一点肉鸽元素。给我多子代理一起做”，编排定，主创授权“你自己决定”；§九.8、合同 §15、实现合同 `docs/cards/rogue/ROGUE_V1.md`）：三个新引擎模块（老物件、周末盘账与客源、本局上下文）装在原有模块之后，只追加；物件和客源的效果只借现有的修正项和效果，不掷随机、不出数；盘账由日结那一步开面板，不进手牌、不进打烊清单，不挑第二天作废，所以打烊永远能按；局外档案只在外壳里读写，引擎只拿到外壳交进来的“这是第几本、什么开头、以前见过哪些碎片”，种子第一本固定 7、以后推出来、不读墙钟；没有这套数据（例子集）或规则文件关掉时，状态和视图一字不变；黄金种子在数据合入后一次重算。
