# 1950–1953 的政策与经济事件，1956 年初收尾

这些牌全部 `weight: 0`，只按年份日程发。没有随机的坏结果。不写斗争会，不写暴力。查到 `kp.history_issue` 时，只走这张事件已经写明的那一条，不另加惩罚。

结局文字由人类 A 写。设计上不称赞、不责备。

## 明确不做

- 禁止批斗，禁止游街，禁止抄家；这些场面不描写，也不做成牌。
- 不因为本心或风声每天掷一次坏处。
- 不在收尾牌上写赞扬或责备。
- 1950–1953 不使用 `game_over`。关不上的情况仍回到当铺年代已有的钱不够 / 街头规则，而那些规则不在这三年的政策牌里额外加重。
