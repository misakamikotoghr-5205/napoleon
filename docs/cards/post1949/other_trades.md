# 另外四个行当（方向，不展开牌表）

和信托商店、茶馆一样：只接到 1956 年初那一张合营收尾；1950–1953 共用 `policy_events.md` 的三张日程牌，不各自再做一套随机惩罚。数量以后再定，这里不列样例牌。

## 中药铺

陈文庭那条人脉。验药材沿用称分量（克、分，工具仍是秤）。抓方子是一张事件：格子收药材类别的货和 `self`，`check.need` 小，没过只是这张方子明天再来，不伤人。老主顾换成来求药的人。收尾：公私合营的药店，玩家是私方人员。

## 杂货铺

凭票和配给。牌以生活牌和 money/goods 通知为主。记账沿用茶馆「记茶钱」的同一套物理参数（座位改成货柜，茶钱改成标价），不新做一种隐藏算法。没有货时通知写明缺什么，不因此随机封铺。收尾：公私合营的杂货店。

## 修理铺

修表、修钟、修收音机。小游戏方向是拆装：参数只有零件个数、螺丝的位置矩形、已经归位的个数。观察键只记哪一颗还松着，不判修得好不好。修不好的结果是这张活明天还在（`expires_days` 延续），不砸东西、不罚一笔随机的钱。收尾：公私合营的修理部。

## 教书 / 代写书信

李敬之那条线。牌以人物和消息为主。代写是读一封信、写一封回信：观察键是信里已经写明的称谓和日期，不考试、不打分。识字不做成题库。人来求写，写成了就 `dossier` 或 `news`，写成不了就这张牌还在手上直到期限。收尾：学校或写信的地方合营，玩家是私方人员。正文仍由 A 写，不作褒贬。
