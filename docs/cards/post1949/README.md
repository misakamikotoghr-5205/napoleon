## 史实措辞（摘录，不是正文）

依据 `docs/town/cards/src/era.json` 的 `notes`、`pivot_intro`、`branch_end`：

- 1949 年那一关以解放收尾。银元重新成为硬通货，当铺在新的利率规定下难以为继，陆续歇业。一些城市开设人民银行的小额抵押贷款机构和国营的信托商店（旧货寄售）。玩家选一个新行当。
- 1950–1953 年的土地改革、「五反」、统购统销只作为政策和经济事件：查账、乡下的当户不再来、凭票买粮。不写成斗争会，不写暴力，不做成随机惩罚。
- 1956 年初各行当以公私合营收尾。结局文字由人类 A 写，设计上不作褒贬。
- 沦陷年代若必须点到旧政权，用「伪」字（伪维持会、伪县政府）。本目录的年代在解放之后，不把 1950 年代写成沦陷叙事。

## 和当铺年代共用什么

- 人、钱、档案碎片、留着的牌、条子的「类 / 档 / 期限 / 办法」这些字段继续用合同 §4 的格式。
- 不改已有命名空间的含义（合同 §6.1）。新行当的进度放进新的命名空间。
- 新手指引继续用已经预留的 `gd.branch_pick` / `rule.branch`。新行当自己的第一次，要新的 first-time 和锚点，走 `[api]`，不改 `CardIds`。
