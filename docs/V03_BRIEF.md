## 吸收自 Probably Stolen（当铺适用）
- 客人意图单一：买 / 卖 / 又卖又买 / 对话 / 鉴定 / 收租…
- 买价修正与卖价修正分开；协商价与标价分开存
- 预算硬门槛；多件购买可关 → v0.3 先做「单件购买」清晰功能
- 议价类型：打折/加价；糟糕议价可拒；最多 N 轮后离开
- 议价中可交互（验货、放回柜台看货、查账簿、点家具）而不只改数字
- 晨报/日历家具化；日终结算
- 客人冷却与到访追踪（已有可复用）
- 不吸收：化学、突袭、飞船、射击、器官等科幻线

## P0（必须进本切片）
1. **侧边对白**：删除大居中对话框；玩家与 NPC 台词出现在说话人旁（气泡或侧栏）。推进/跳过/退出仍可用，无软锁。
2. **放大镜返回**：鉴定后必须能回到柜台看货品（修「无法返回看货品」）。
3. **提示与万年历**：删全局「待办」「提示」HUD 刷屏；日历变可点万年历家具；情境提示贴在物品旁，发光后淡出消失。
4. **算盘**：去掉计算器感；模拟算盘 + 嘴说报价短教程。
5. **经济统一**：统一顾客定价；改善高买低卖体感；顾客可单独买一件库存商品（一个清晰功能）；砍价仍干净退出；议价中可做简单交互。
6. **玩家自主**：多可点选择（验什么、说什么、做什么），非线性点穿。
